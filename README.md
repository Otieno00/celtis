# CELTIS - Civil Engineering Laboratory Test Information System

CELTIS is a Python-based desktop application designed for civil engineering laboratories to manage, track, and analyze test data. It features a modern graphical interface, automated report generation, and a visual dashboard for monitoring test results.

## ✨ Features
*   **Test Management:** Keep track of data for Concrete, Soil, Aggregate, and Asphalt tests.
*   **Automated Reports:** Generate professional PDF and Word (`.docx`) reports instantly.
*   **Visual Dashboard:** View data trends and statistics using integrated Matplotlib charts.
*   **Offline Database:** Uses SQLite for secure, local data storage—no internet required.
*   **Trial Version:** Includes a built-in 30-day trial limit.

## 🚀 How to Install and Run (For Regular Users)
You do not need to install Python to use the app. 

1. Go to the **Releases** section on the right side of this GitHub page.
2. Download the latest `CELTIS_v1.0.zip` file.
3. Extract the ZIP file to a folder on your computer.
4. Ensure that **`CELTIS.exe`** and **`civil_engineering_lab.db`** are in the same folder.
5. Double-click `CELTIS.exe` to launch the app!
